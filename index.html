Hotel Booking System

MySQLSQLER Design

A relational database for hotel room reservations. It stores rooms, guests and bookings, and uses foreign keys with cascading deletes to keep the data consistent. The project includes the ER diagram, table definitions, sample data and analysis queries.

My part

  • Contributed to the team's schema and ER design (team of five).
  • Wrote queries using RIGHT JOIN across three tables and nested subqueries.
SELECT g.name AS guest_name, r.room_type, b.check_in_date
FROM Rooms r
RIGHT JOIN Bookings b ON r.room_id = b.room_id
RIGHT JOIN Guests g ON b.guest_id = g.guest_id;
